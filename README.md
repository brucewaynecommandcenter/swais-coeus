# SWAIS COEUS website

Static, dependency-free site for SWAIS COEUS (Saraf Worldsphere AI Services), built for the European market.

- `index.html` – single page
- `assets/css/styles.css`, `assets/js/main.js`
- `assets/fonts` – self-hosted Sora and Inter (no Google Fonts calls, GDPR friendly)
- No cookies, trackers or third-party requests. Contact form opens the visitor's email app.

## Deploy on GitHub Pages
Settings → Pages → Deploy from branch → `main` / root.
